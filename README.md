# Ball Race 🏁

An interactive **ball racing game** where colorful balls compete against each other in a race.

The project focuses on creating animations, movement, and interactive gameplay mechanics.

## 🎮 Features

- 🏁 Ball racing
- ⚪ Multiple colorful balls
- 🎲 Competitive gameplay
- 💨 Animated ball movement
- 🏆 Race results
- 🎨 Custom visual design
- ⚡ Interactive gameplay

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 📚 Learning Project

This project was created as a **learning project at Creator IT Academy**.

It was developed to practice JavaScript, animations, movement, and interactive gameplay mechanics.
